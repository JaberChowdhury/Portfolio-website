A pointer is a variable that stores the memory address of another variable.

In Competitive Programming, pointers are not heavily used directly, but understanding basic pointer concepts helps in:

- Understanding arrays
    
- Understanding references
    
- Passing arrays to functions
    
- Dynamic memory concepts (later topics)
    

---

## **1. Basic Pointer Concept**

### 📘 Theory

Every variable in C++ is stored in memory.

A pointer stores the **address** of a variable.

---

### 🔹 Syntax

```cpp
data_type *pointer_name;
```

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 10;
    int *p = &a;

    cout << p;

    return 0;
}
```

---

### 🖥 Output (Example)

```
0x61ff08   // memory address (varies each run)
```

---

### 📘 Explanation

- `a` → stores value `10`
    
- `&a` → gives address of `a`
    
- `p` → stores that address
    

---

## **2. Address Operator (`&`)**

### 📘 Theory

The `&` operator gives the address of a variable.

---

### 💻 Example

```cpp
int a = 5;

cout << &a;
```

Output:

```
(memory address of a)
```

---

## **3. Dereference Operator (`*`)**

### 📘 Theory

The `*` operator is used to access the value stored at an address.

This is called **dereferencing**.

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 10;
    int *p = &a;

    cout << *p;

    return 0;
}
```

---

### 🖥 Output

```
10
```

---

### 📘 Explanation

- `p` → stores address
    
- `*p` → accesses value at that address
    

---

## **4. Changing Value Using Pointer**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 10;
    int *p = &a;

    *p = 50;

    cout << a;

    return 0;
}
```

---

### 🖥 Output

```
50
```

Changing `*p` changes `a`.

---

## **5. Array and Pointer Relationship**

### 📘 Theory

Array name behaves like a pointer to its first element.

If:

```cpp
int arr[5] = {1, 2, 3, 4, 5};
```

Then:

```
arr == &arr[0]
```

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int arr[3] = {10, 20, 30};

    cout << arr << "\n";        // address of first element
    cout << &arr[0] << "\n";    // same address

    return 0;
}
```

---

### 📘 Access Using Pointer

```cpp
int *p = arr;

cout << *p << "\n";       // 10
cout << *(p + 1) << "\n"; // 20
```

---

## **6. Passing Array to Function (Array Parameter Idea)**

### 📘 Theory

When an array is passed to a function, it is passed as a pointer.

That means:

- The original array can be modified inside the function.
    

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

void modify(int arr[], int n) {

    arr[0] = 100;
}

int main() {

    int arr[3] = {1, 2, 3};

    modify(arr, 3);

    cout << arr[0];

    return 0;
}
```

---

### 🖥 Output

```
100
```

---

### 📘 Important Note

These two are equivalent:

```cpp
void modify(int arr[], int n)
```

```cpp
void modify(int *arr, int n)
```

Both receive a pointer to the first element.
