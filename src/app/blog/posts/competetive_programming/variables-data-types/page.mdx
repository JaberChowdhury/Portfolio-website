## **1. Variables &amp; Naming Rules**

### 📘 Theory

A **variable** is a named memory location used to store data.

Before using a variable, we must:

1. Declare it
    
2. Assign a value (optional at declaration)
    

---

### 💻 Example

```cpp
int age = 20;
double price = 99.5;
char grade = 'A';
```

---

### 📘 Naming Rules

- Must begin with a letter or underscore `_`
    
- Cannot start with a number
    
- Cannot use spaces
    
- Cannot use C++ keywords (like `int`, `return`)
    
- Case-sensitive (`age` and `Age` are different)
    

---

### ✅ Valid Examples

```cpp
int number;
int _count;
double totalMarks;
```

### ❌ Invalid Examples

```cpp
int 2number;   // starts with number
int total marks;  // space not allowed
```

---

## **2. Data Types in C++**

### 📘 Theory

Data types define what kind of data a variable can store.

---

### 🔹 Integer Types

```cpp
int a = 10;
long long b = 10000000000;
```

Used for whole numbers.

---

### 🔹 Floating Point Types

```cpp
double pi = 3.14159;
```

Used for decimal numbers.

---

### 🔹 Character Type

```cpp
char letter = 'A';
```

Stores a single character (inside single quotes).

---

### 🔹 Boolean Type

```cpp
bool isPassed = true;
```

Stores only:

- `true`
    
- `false`
    

---

## **3. Range of Data Types**

Each data type has a fixed memory size.

| Data Type | Size (bytes) | Approximate Range |
| --------- | ------------ | ----------------- |
| int       | 4            | -2×10⁹ to 2×10⁹   |
| long long | 8            | -9×10¹⁸ to 9×10¹⁸ |
| double    | 8            | ±10³⁰⁸            |
| char      | 1            | -128 to 127       |
| bool      | 1            | true / false      |

---

### 💻 Check Size Using `sizeof`

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    cout << sizeof(int) << endl;
    cout << sizeof(long long) << endl;

    return 0;
}
```

---

### 🖥 Output (Usually)

```
4
8
```

---

## **4. Why `long long` is Important in CP**

### 📘 Theory

In Competitive Programming:

Constraints are often large:

```
1 ≤ n ≤ 10^18
```

If you use `int`, it will overflow.

So we use:

```cpp
long long
```

For:

- Large numbers
    
- Multiplication
    
- Sum of large arrays
    

---

### 💻 Example

```cpp
long long a = 1000000000;
long long b = 1000000000;

cout << a * b;
```

If `int` was used, it would overflow.

---

## **5. `sizeof` Operator**

### 📘 Theory

`sizeof` returns the size of a variable or data type in bytes.

---

### 💻 Example

```cpp
int x;
cout << sizeof(x);
```

Output:

```
4
```

## **6. `const` Keyword**

### 📘 Theory

`const` makes a variable constant.  
Its value cannot be changed later.

---

### 💻 Example

```cpp
const int MAX = 100;

MAX = 200;  // Error
```

---

### Why Use `const`?

- Fixed values
    
- Prevent accidental changes
    
- Good coding practice
    

---

## **7. `auto` (Short Introduction)**

### 📘 Theory

`auto` automatically detects the variable type.

---

### 💻 Example

```cpp
auto x = 10;      // int
auto y = 3.14;    // double
auto ch = 'A';    // char
```

The compiler determines the type automatically.

Useful in:

- Loops
    
- STL (later in CP)
    

---

## **8. Type Casting**

### 📘 Theory

Type casting converts one data type into another.

---

### 🔹 Implicit Type Casting

Done automatically by compiler.

```cpp
int a = 5;
double b = a;  // int to double
```

---

### 🔹 Explicit Type Casting

Done manually.

```cpp
double x = 5.8;
int y = (int)x;
```

---

### 🖥 Output

If `x = 5.8`

```
y = 5
```

Decimal part is removed.

---

## **9. Integer Overflow Example**

### 📘 Theory

Overflow happens when a value exceeds the limit of its data type.

---

### 💻 Example (Overflow)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 1000000000;
    int b = 1000000000;

    cout << a * b;

    return 0;
}
```

---

### 🖥 Output (Wrong due to overflow)

```
Some incorrect negative value
```

---

### ✅ Correct Version

```cpp
long long a = 1000000000;
long long b = 1000000000;

cout << a * b;
```

Now it works correctly.

---

## **10. Swap Two Numbers**

### 📘 Method 1: Using Temporary Variable

```cpp
int a = 5;
int b = 10;

int temp = a;
a = b;
b = temp;
```

---

### 📘 Method 2: Without Temporary Variable

```cpp
int a = 5;
int b = 10;

a = a + b;
b = a - b;
a = a - b;
```

⚠ Be careful: This may overflow for large numbers.

---

### 📘 Method 3: Using `swap()` (Recommended in CP)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 5, b = 10;
    swap(a, b);

    cout << a << " " << b;

    return 0;
}
```

---

### 🖥 Output

```
10 5
```
