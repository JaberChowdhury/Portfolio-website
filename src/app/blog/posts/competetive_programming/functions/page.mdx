A function is a reusable block of code that performs a specific task.

In Competitive Programming, functions help:

- Break large problems into smaller parts
    
- Avoid code repetition
    
- Improve readability
    

---

## **1. Function Syntax**

### 📘 Theory

A function consists of:

- Return type
    
- Function name
    
- Parameters
    
- Function body
    

---

### 🔹 Syntax

```cpp
return_type function_name(parameters) {
    // code
    return value;
}
```

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {

    cout << add(5, 3);

    return 0;
}
```

---

### 🖥 Output

```
8
```

---

## **2. Call by Value**

### 📘 Theory

In call by value, a copy of the variable is passed.

Changes inside the function do NOT affect the original variable.

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

void change(int x) {
    x = 100;
}

int main() {

    int a = 10;
    change(a);

    cout << a;

    return 0;
}
```

---

### 🖥 Output

```
10
```

Original value remains unchanged.

---

## **3. Call by Reference**

### 📘 Theory

In call by reference, the original variable is passed using `&`.

Changes inside the function affect the original variable.

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

void change(int &x) {
    x = 100;
}

int main() {

    int a = 10;
    change(a);

    cout << a;

    return 0;
}
```

---

### 🖥 Output

```
100
```

---

## **4. Default Arguments**

### 📘 Theory

Default arguments allow a function parameter to have a default value.

If no value is provided, the default value is used.

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int multiply(int a, int b = 2) {
    return a * b;
}

int main() {

    cout << multiply(5) << "\n";      // uses default
    cout << multiply(5, 3);           // overrides default

    return 0;
}
```

---

### 🖥 Output

```
10
15
```

## **5. Inline Function (Short Introduction)**

### 📘 Theory

An inline function suggests the compiler replace the function call with actual code.

Used for very small functions to reduce function call overhead.

---

### 💻 Example

```cpp
inline int square(int x) {
    return x * x;
}
```

Used like normal function.

---

### 📘 Note

Modern compilers automatically optimize small functions.  
In CP, explicit `inline` is rarely necessary.

## **6. Recursion (Introduction)**

### 📘 Theory

Recursion is when a function calls itself.

Every recursive function must have:

- Base case (stopping condition)
    
- Recursive call
    

---

### 💻 Example: Factorial

```cpp
#include <bits/stdc++.h>
using namespace std;

long long factorial(int n) {

    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}

int main() {

    cout << factorial(5);

    return 0;
}
```

---

### 🖥 Output

```
120
```

---

### 📘 Important Note

Without base case → infinite recursion → stack overflow.

## **7. Prime Factorization**

### 📘 Theory

Prime factorization breaks a number into its prime factors.

Example:

```
12 = 2 × 2 × 3
```

---

### 💻 Code

```cpp
#include <bits/stdc++.h>
using namespace std;

void primeFactorization(int n) {

    for(int i = 2; i * i <= n; i++) {
        while(n % i == 0) {
            cout << i << " ";
            n /= i;
        }
    }

    if(n > 1)
        cout << n;
}

int main() {

    int n;
    cin >> n;

    primeFactorization(n);

    return 0;
}
```

---

### 📘 Time Complexity

Approximately:

```
O(√n)
```

## **8. First Digit Extraction**

### 📘 Method 1: Using Loop

```cpp
int firstDigit(int n) {

    while(n >= 10) {
        n /= 10;
    }

    return n;
}
```

---

### 💻 Example

```cpp

        n /= 10;

    return n;
}

    cout << firstDigit(12345);

    return 0;
}
```

### 🖥 Output

```
1
```
