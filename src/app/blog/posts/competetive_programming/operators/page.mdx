# **OPERATORS IN C++**

Operators are symbols used to perform operations on variables and values.

---

## **1. Arithmetic Operators**

### 📘 Theory

Arithmetic operators are used to perform mathematical calculations.

---

### 🔹 List of Arithmetic Operators

|Operator|Meaning|
|---|---|
|`+`|Addition|
|`-`|Subtraction|
|`*`|Multiplication|
|`/`|Division|
|`%`|Modulus (Remainder)|

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 10, b = 3;

    cout << "Addition: " << a + b << "\n";
    cout << "Subtraction: " << a - b << "\n";
    cout << "Multiplication: " << a * b << "\n";
    cout << "Division: " << a / b << "\n";
    cout << "Modulus: " << a % b << "\n";

    return 0;
}
```

---

### 🖥 Output

```
Addition: 13
Subtraction: 7
Multiplication: 30
Division: 3
Modulus: 1
```

---

### 📘 Important Notes

-  `/` Integer division removes decimal part.
    
- `%` works only with integers.
    

---

## **2. Comparison Operators**

### 📘 Theory

Comparison operators compare two values and return:

- `true` (1)
    
- `false` (0)
    

---

### 🔹 List of Comparison Operators

|Operator|Meaning|
|---|---|
|`==`|Equal|
|`!=`|Not equal|
|`>`|Greater than|
|`<`|Less than|
|`>=`|Greater than or equal|
|`<=`|Less than or equal|

---

### 💻 Example 

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 5, b = 10;

    cout << (a == b) << "\n";
    cout << (a != b) << "\n";
    cout << (a < b) << "\n";
    cout << (a > b) << "\n";

    return 0;
}
```

---

### 🖥 Output

```
0
1
1
0
```

---

## **3. Logical Operators**

### 📘 Theory

Logical operators combine comparison results.

---

### 🔹 List of Logical Operators

| Operator | Meaning |
| -------- | ------- |
| `&&`     | AND     |
| `ll`     | OR      |
| `!`      | NOT     |

---

### 💻 Example 

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 5, b = 10;

    cout << ((a < b) && (a > 0)) << "\n";
    cout << ((a > b) || (a > 0)) << "\n";
    cout << !(a < b) << "\n";

    return 0;
}
```

---
### 🖥 Output

```
1
1
0
```

---

### 📘 Explanation

- `&&` → Both conditions must be true
    
- `||` → At least one condition must be true
    
- `!` → Reverses the result

---
## **4. Assignment Operators**

### 📘 Theory

Assignment operators assign values to variables.

---

### 🔹 Basic Assignment

```cpp
int a = 5;
```

---

### 🔹 Compound Assignment

|Operator|Meaning|
|---|---|
|`+=`|a = a + value|
|`-=`|a = a - value|
|`*=`|a = a * value|
|`/=`|a = a / value|
|`%=`|a = a % value|

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int x = 10;

    x += 5;
    cout << x << "\n";  // 15

    x *= 2;
    cout << x << "\n";  // 30

    return 0;
}
```

---

## **5. Operator Precedence**

### 📘 Theory

Operator precedence decides which operation happens first.

Example:

```cpp
int result = 2 + 3 * 4;
```

Multiplication happens before addition.

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    cout << 2 + 3 * 4 << "\n";
    cout << (2 + 3) * 4 << "\n";

    return 0;
}
```

---

### 🖥 Output

```
14
20
```

---

### 📘 Important Rule

If confused, use parentheses `()`.

```cpp
int result = (2 + 3) * 4;  // 20
```

---

### 🔹 Basic Precedence Order (High → Low)

1. `()`
    
2. `* / %`
    
3. `+ -`
    
4. Comparison operators
    
5. Logical operators
    

---

## **6. Bitwise Operators (Basic Only)**

### 📘 Theory

Bitwise operators work on binary form of numbers.

---

### 🔹 List of Bitwise Operators

| Operator | Meaning     |
| -------- | ----------- |
| `&`      | AND         |
| `l`      | OR          |
| `^`      | XOR         |
| `~`      | NOT         |
| `<<`     | Left shift  |
| `>>`     | Right shift |

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 5;  // 101
    int b = 3;  // 011

    cout << (a & b) << "\n";
    cout << (a | b) << "\n";
    cout << (a ^ b) << "\n";

    return 0;
}
```

---

### 🖥 Output

```
1
7
6
```

---
### 📘 Explanation

Binary:

```
5 = 101
3 = 011
```

- AND → 001 = 1
    
- OR → 111 = 7
    
- XOR → 110 = 6

## **7. Modulo Operator Importance in CP**

### 📘 Theory

The modulo operator `%` gives the remainder.

It is very important in CP for:

- Last digit extraction
    
- Even/odd checking (later with condition)
    
- Large number handling
    
- Modular arithmetic
    

---

### 💻 Example 1: Last Digit

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int n = 12345;
    cout << n % 10;

    return 0;
}
```

Output:

```
5
```

---

### 💻 Example 2: Even/Odd Result 

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int n = 8;
    cout << n % 2;

    return 0;
}
```

Output:

```
0
```

Explanation:

- If result is 0 → number is even
    
- If result is 1 → number is odd
    

(No `if` used)

---

## 💻 Example 3: Sum of First N Natural Numbers (Formula Only)

```cpp
long long n;
cin >> n;  // 3

cout << n * (n + 1) / 2;
```

Output:

```
6
```

No loop used.
