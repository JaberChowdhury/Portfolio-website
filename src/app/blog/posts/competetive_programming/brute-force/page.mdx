Brute force is the simplest problem-solving approach.

It means:

&gt; Try all possible solutions and choose the correct one.

In Competitive Programming, brute force is often:

- The first approach you think of
    
- Useful for small constraints
    
- A stepping stone to optimized solutions
    

---

## **1. What is Brute Force?**

### 📘 Theory

Brute force means solving a problem by checking every possible case without using optimization techniques.

It usually involves:

- Nested loops
    
- Checking all pairs
    
- Trying all substrings
    
- Trying all combinations
    

---

### 📘 When to Use Brute Force?

- When constraints are small
    
- When `n ≤ 1000` or smaller
    
- When building initial logic
    

---

### 📘 When NOT to Use?

If constraints are large:

```
n ≤ 10^5
```

Then `O(n²)` solutions will likely be too slow.

# **2. Pair Sum (Brute Force Example)**

### 📘 Problem

Given an array of size `n`, check if any two elements sum to a given target.

---

### 💻 Brute Force Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int n, target;
    cin >> n >> target;

    int arr[n];
    for(int i = 0; i < n; i++)
        cin >> arr[i];

    bool found = false;

    for(int i = 0; i < n; i++) {
        for(int j = i + 1; j < n; j++) {

            if(arr[i] + arr[j] == target) {
                found = true;
                break;
            }
        }
    }

    if(found)
        cout << "Pair Found";
    else
        cout << "Pair Not Found";

    return 0;
}
```

---

### 📘 Time Complexity

Two nested loops:

```
O(n²)
```

---

### 📘 Why Brute Force?

We check all possible pairs:

```
(n × (n-1)) / 2
```

Possible combinations.

# **3. Substring (Brute Force Example)**

### 📘 Problem

Print all substrings of a string.

Example:

```
abc
```

Substrings:

```
a
ab
abc
b
bc
c
```

---

### 💻 Brute Force Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    string s;
    cin >> s;

    int n = s.length();

    for(int i = 0; i < n; i++) {
        for(int len = 1; len <= n - i; len++) {

            cout << s.substr(i, len) << "\n";
        }
    }

    return 0;
}
```

---

### 📘 Time Complexity

Outer loop runs `n` times.  
Inner loop runs up to `n` times.

Total complexity:

```
O(n²)
```

If printing each substring fully:

```
O(n³)
```

---

# **4. Time Complexity Analysis of Brute Force**

Brute force solutions often have:

|Pattern|Complexity|
|---|---|
|Single loop|O(n)|
|Two nested loops|O(n²)|
|Three nested loops|O(n³)|
|Recursive brute|O(2ⁿ)|

---

### 📘 Important CP Insight

If constraints are:

```
n ≤ 10^3 → O(n²) acceptable
n ≤ 10^5 → O(n²) too slow
```

---

### 📘 Example

If:

```
n = 10^5
```

Then:

```
n² = 10^10 operations ❌ Too slow
```
