## **1. What is Programming?**

### 📘 Theory

Programming is the process of giving instructions to a computer to perform specific tasks.  
These instructions are written in a programming language.

A program:

- Takes input
    
- Processes the data
    
- Produces output
    

This is commonly called:

&gt; **Input → Process → Output**

In Competitive Programming (CP), programming is mainly used to solve algorithmic problems efficiently.

---

## **2. Why C++ for Competitive Programming?**

### 📘 Theory

C++ is one of the most popular languages for CP because:

- ⚡ Very fast execution speed
    
- 📚 Powerful Standard Template Library (STL)
    
- 🎯 Direct memory control
    
- 🏆 Used in most programming contests
    

Many platforms like Codeforces, AtCoder, ICPC widely use C++.

---

## **3. Structure of a C++ Program**

### 📘 Basic Structure

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    // Your code here

    return 0;
}
```

---

### 📘 Explanation

|Part|Meaning|
|---|---|
|`#include`|Includes library files|
|`<bits/stdc++.h>`|Includes almost all standard libraries|
|`using namespace std;`|Allows us to use standard library without writing `std::`|
|`int main()`|Entry point of program|
|`return 0;`|Program ends successfully|

---

## **4. First Code (Hello World)**

### 💻 Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello World";
    return 0;
}
```

---

### 🖥 Output

```
Hello World
```

---

### 📘 Explanation

- `cout` is used to print output.
    
- `<<` is the insertion operator.
    
- Text must be inside double quotes.

## **5. Comments in C++**

### 📘 Theory

Comments are used to explain code.  
They are ignored by the compiler.

---

### 🔹 Single Line Comment

```cpp

```

---

### 🔹 Multi-Line Comment

```cpp

a multi-line
comment
*/
```

---

### 💻 Example

```cpp

```

---

## **6. Header File (`<bits/stdc++.h>`)**

### 📘 Theory

A header file contains pre-written functions and tools.

Example:

```cpp
#include <iostream>
```

But in CP, we usually use:

```cpp
#include <bits/stdc++.h>
```

### Why?

- It includes almost all standard libraries.
    
- Saves time during contests.
    
- Reduces need to remember multiple headers.
    

⚠ Note:  
`<bits/stdc++.h>` is mostly available in GCC compiler.

---

## **7. Namespace in C++ (`std`)**

### 📘 Theory

C++ standard functions like `cout`, `cin`, `vector`, etc. belong to the `std` namespace.

Without using namespace:

```cpp
std::cout << "Hello";
```

With namespace:

```cpp
using namespace std;
cout << "Hello";
```

### 💡 Why use it?

It makes the code shorter and cleaner.

## **8. Basic CP Template  --- X**

In Competitive Programming, we use a standard template.

---

### 💻 Basic Template

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    cin >> t;

    while(t--) {
        // solve test case here
    }

    return 0;
}
```

---

### 📘 Explanation

|Line|Purpose|
|---|---|
|`ios::sync_with_stdio(false);`|Makes input/output faster|
|`cin.tie(NULL);`|Prevents unnecessary flushing|
|`int t;`|Number of test cases|
|`while(t--)`|Loop over test cases|

---

### 🖥 Example Input

```
3
1
2
3
```

### 🖥 Example Output (if printing input)

```
1
2
3
```
