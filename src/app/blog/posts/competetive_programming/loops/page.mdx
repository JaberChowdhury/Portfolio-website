Loops are used to execute a block of code multiple times.

In Competitive Programming, loops are extremely important because most problems involve repetition.

---

## **1. For Loop**

### 📘 Theory

A `for` loop is used when the number of iterations is known.

---

### 🔹 Syntax

```cpp
for(initialization; condition; update) {
    // code to repeat
}
```

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    for(int i = 1; i <= 5; i++) {
        cout << i << " ";
    }

    return 0;
}
```

---

### 🖥 Output

```
1 2 3 4 5
```

---

### 📘 Explanation

- Initialization → runs once
    
- Condition → checked before each iteration
    
- Update → runs after each iteration
    

---

## **2. While Loop**

### 📘 Theory

A `while` loop is used when the number of iterations is unknown.

---

### 🔹 Syntax

```cpp
while(condition) {
    // code
}
```

---

### 💻 Example

```cpp
int i = 1;

while(i <= 5) {
    cout << i << " ";
    i++;
}
```

---

## **3. Do-While Loop**

### 📘 Theory

The `do-while` loop executes the block at least once, even if the condition is false.

---

### 🔹 Syntax

```cpp
do {
    // code
} while(condition);
```

---

### 💻 Example

```cpp
int i = 1;

do {
    cout << i << " ";
    i++;
} while(i <= 5);
```

---

## **4. Break and Continue**

---

### 🔹 Break

Stops the loop immediately.

```cpp
for(int i = 1; i <= 5; i++) {
    if(i == 3)
        break;

    cout << i << " ";
}
```

Output:

```
1 2
```

---

### 🔹 Continue

Skips current iteration.

```cpp
for(int i = 1; i <= 5; i++) {
    if(i == 3)
        continue;

    cout << i << " ";
}
```

Output:

```
1 2 4 5
```

---

## **5. Nested Loops**

### 📘 Theory

A loop inside another loop is called a nested loop.

---

### 💻 Example

```cpp
for(int i = 1; i <= 3; i++) {
    for(int j = 1; j <= 3; j++) {
        cout << "* ";
    }
    cout << "\n";
}
```

Output:

```
* * *
* * *
* * *
```

# 🧪 PRACTICE PROBLEMS

---

## **1. Factorial**

```cpp
long long n;
cin >> n;

long long fact = 1;

for(int i = 1; i <= n; i++) {
    fact *= i;
}

cout << fact;
```

---

## **2. Count Digits**

```cpp
int n;
cin >> n;

int count = 0;

while(n > 0) {
    count++;
    n /= 10;
}

cout << count;
```

---

## **3. Prime Check**

```cpp
int n;
cin >> n;

bool isPrime = true;

if(n <= 1)
    isPrime = false;

for(int i = 2; i * i <= n; i++) {
    if(n % i == 0) {
        isPrime = false;
        break;
    }
}

if(isPrime)
    cout << "Prime";
else
    cout << "Not Prime";
```

---

## **4. GCD**

```cpp
int a, b;
cin >> a >> b;

while(b != 0) {
    int temp = b;
    b = a % b;
    a = temp;
}

cout << a;
```

---

## **5. LCM**

```cpp
int a, b;
cin >> a >> b;

int originalA = a;
int originalB = b;

while(b != 0) {
    int temp = b;
    b = a % b;
    a = temp;
}

int gcd = a;

cout << (originalA * originalB) / gcd;
```

---

## **6. Fibonacci Series (First N Terms)**

```cpp
int n;
cin >> n;

int a = 0, b = 1;

for(int i = 1; i <= n; i++) {
    cout << a << " ";
    int next = a + b;
    a = b;
    b = next;
}
```

## **7. All Divisors of a Number**

```cpp
int n;
cin >> n;

for(int i = 1; i <= n; i++) {
    if(n % i == 0)
        cout << i << " ";
```

## **8. Palindrome Number**

```cpp
int n;
cin >> n;

int original = n;
int reversed = 0;

while(n > 0) {
    reversed = reversed * 10 + (n % 10);
    n /= 10;
}

if(original == reversed)
    cout << "Palindrome";
else
    cout << "Not Palindrome";
```
