A reference is an alias (another name) for an existing variable.

In Competitive Programming, references are useful for:

- Avoiding unnecessary copying
    
- Passing large data structures efficiently
    
- Modifying variables inside functions
    

---

## **1. Reference Variable**

### 📘 Theory

A reference variable is declared using `&`.

It does not create a new variable.  
It simply refers to an existing variable.

---

### 🔹 Syntax

```cpp
data_type &reference_name = original_variable;
```

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int a = 10;
    int &ref = a;

    ref = 20;

    cout << a;

    return 0;
}
```

---

### 🖥 Output

```
20
```

---

### 📘 Explanation

- `ref` is not a new variable.
    
- It refers to `a`.
    
- Changing `ref` changes `a`.
    

---

### 📘 Important Rules

- A reference must be initialized at declaration.
    
- A reference cannot be changed to refer to another variable later.
    

---

## **2. Range-Based For Loop with Reference**

### 📘 Theory

In C++11 and later, we can use range-based for loops.

Without reference → elements are copied.  
With reference → original elements are modified.

---

### 🔹 Normal Range Loop (Copy)

```cpp
int arr[5] = {1, 2, 3, 4, 5};

for(int x : arr) {
    x += 10;
}
```

This does NOT change original array.

---

### 🔹 Range Loop with Reference

```cpp
int arr[5] = {1, 2, 3, 4, 5};

for(int &x : arr) {
    x += 10;
}

for(int x : arr) {
    cout << x << " ";
}
```

---

### 🖥 Output

```
11 12 13 14 15
```

---

### 📘 Why Important in CP?

When using:

- Large arrays
    
- Vectors
    
- Strings
    

Using reference avoids copying and improves performance.

---

## **3. `const` Reference**

### 📘 Theory

A `const` reference prevents modification of the original variable.

Used when:

- We want to avoid copying
    
- But do not want to modify data
    

---

### 💻 Example

```cpp
#include <bits/stdc++.h>
using namespace std;

void printValue(const int &x) {
    cout << x;
}

int main() {

    int a = 50;
    printValue(a);

    return 0;
}
```

---

### 📘 Why Use `const` Reference?

Suppose we pass a large vector:

Without reference:

- Entire vector is copied.
    

With `const` reference:

- No copy
    
- Safe from modification
    

---

### 💻 Example with Vector

```cpp
#include <bits/stdc++.h>
using namespace std;

void printVector(const vector<int> &v) {

    for(int x : v)
        cout << x << " ";
}

int main() {

    vector<int> v = {1, 2, 3, 4};
    printVector(v);

    return 0;
}
```
