A Greedy algorithm builds a solution step by step, always choosing the option that looks best at the current moment.

It makes a **locally optimal choice**, hoping it leads to a **globally optimal solution**.

---

## **1. Idea of Greedy**

### 📘 Theory

Greedy approach works on the principle:

&gt; Choose the best possible option right now, without reconsidering previous choices.

Greedy does NOT:

- Try all possibilities
    
- Use recursion/backtracking
    
- Look ahead deeply
    

---

### 📘 Example Idea

If you want to reach the highest score:

- At each step, choose the maximum available value.
    

Greedy decisions are:

- Fast
    
- Simple
    
- Often optimal (but not always)
    

---

### 📘 When to Use Greedy?

Greedy works when:

- Problem has optimal substructure
    
- Local optimal choice leads to global optimum

# **2. Activity Selection Problem**

### 📘 Problem

You are given activities with:

- Start time
    
- Finish time
    

Select maximum number of non-overlapping activities.

---

### 📘 Greedy Idea

1. Sort activities by finishing time
    
2. Select the activity that finishes first
    
3. Keep selecting the next activity that starts after the last selected one
    

---

### 💻 Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    vector<pair<int,int>> activities = {
        {1, 3},
        {2, 5},
        {4, 6},
        {6, 7},
        {5, 8}
    };

    sort(activities.begin(), activities.end(),
         [](pair<int,int> a, pair<int,int> b) {
             return a.second < b.second;
         });

    int count = 1;
    int lastEnd = activities[0].second;

    for(int i = 1; i < activities.size(); i++) {
        if(activities[i].first >= lastEnd) {
            count++;
            lastEnd = activities[i].second;
        }
    }

    cout << "Maximum activities: " << count;

    return 0;
}
```

---

### 📘 Time Complexity

Sorting:

```
O(n log n)
```

Selection loop:

```
O(n)
```

Total:

```
O(n log n)
```

# **3. Simple Coin Problem (Greedy Version)**

### 📘 Problem

Given coins of denominations:

```
1, 5, 10, 25
```

Find minimum number of coins to make a given amount.

---

### 📘 Greedy Idea

Always take the largest coin possible first.

---

### 💻 Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    int amount;
    cin >> amount;

    vector<int> coins = {25, 10, 5, 1};

    int count = 0;

    for(int coin : coins) {
        count += amount / coin;
        amount %= coin;
    }

    cout << "Minimum coins: " << count;

    return 0;
}
```

---

### 📘 Why It Works Here?

Because these coin denominations are canonical (like US currency).

# **4. When Greedy Fails**

Greedy does NOT always work.

---

### 📘 Example

Coins:

```
1, 3, 4
```

Amount:

```
6
```

Greedy choice:

- Take 4 → remaining 2
    
- Take 1 + 1  
    Total = 3 coins
    

Optimal solution:

- 3 + 3  
    Total = 2 coins
    

Greedy failed ❌

---

### 📘 Why It Failed?

Because the local best choice (4) was not part of the global best solution.

---

# 🔥 Key Insight About Greedy

Greedy works only when:

- The problem satisfies the **greedy choice property**
    
- A proof exists that local choice leads to global optimum
    

Without proof, greedy may fail.

---

# 📌 How to Recognize Greedy Problems

Often involves:

- Sorting
    
- Maximizing or minimizing something
    
- Interval scheduling
    
- Selecting elements under constraints
