In Competitive Programming, writing correct code is not enough.  
The solution must also be **efficient**.

Time and Space Complexity help us measure:

- How fast an algorithm runs
    
- How much memory it uses
    

---

# **1. What is Time Complexity?**

### 📘 Theory

Time Complexity measures how the running time of an algorithm grows as input size increases.

It does NOT measure actual time in seconds.  
It measures how operations grow with input size `n`.

---

### 📘 Example

If a loop runs `n` times:

```cpp
for(int i = 0; i < n; i++) {
    cout << i;
}
```

Time Complexity:

```
O(n)
```

Because operations grow linearly with `n`.

---

# **2. Big-O Notation**

### 📘 Theory

Big-O notation describes the **upper bound** of time complexity.

It focuses on:

- Worst-case growth
    
- Large input behavior
    

---

### 📘 Rules of Big-O

1. Ignore constants
    
    ```
    O(5n) → O(n)
    ```
    
2. Ignore lower order terms
    
    ```
    O(n² + n) → O(n²)
    ```
    
3. Focus on dominant term
    

---

### 📘 Why Big-O is Important?

In CP, constraints often look like:

```
1 ≤ n ≤ 10^5
```

If your algorithm is:

- O(n) → acceptable
    
- O(n²) → too slow
    

---

# **3. Common Time Complexities**

|Complexity|Name|Suitable For|
|---|---|---|
|O(1)|Constant|Direct access|
|O(log n)|Logarithmic|Binary search|
|O(n)|Linear|Single loop|
|O(n log n)|Log-linear|Sorting|
|O(n²)|Quadratic|Nested loops|
|O(2ⁿ)|Exponential|Brute force subsets|

---

### 📘 CP Rule of Thumb

If:

```
n ≤ 10^5 → O(n log n) or O(n)
n ≤ 10^3 → O(n²)
```

---

# **4. Loop Complexity Calculation**

---

### 🔹 Single Loop

```cpp
for(int i = 0; i < n; i++) {
    // constant work
}
```

Complexity:

```
O(n)
```

---

### 🔹 Loop with Constant Bound

```cpp
for(int i = 0; i < 100; i++) {
    cout << i;
}
```

Complexity:

```
O(1)
```

Because 100 is constant.

---

### 🔹 Loop Dividing by 2

```cpp
while(n > 1) {
    n = n / 2;
}
```

Complexity:

```
O(log n)
```

Because input size halves each time.

---

# **5. Nested Loop Complexity**

---

### 🔹 Independent Nested Loop

```cpp
for(int i = 0; i < n; i++) {
    for(int j = 0; j < n; j++) {
        cout << i << j;
    }
}
```

Complexity:

```
O(n²)
```

---

### 🔹 Dependent Nested Loop

```cpp
for(int i = 0; i < n; i++) {
    for(int j = 0; j < i; j++) {
        cout << i << j;
    }
}
```

Still:

```
O(n²)
```

---

### 🔹 Triple Nested Loop

```cpp
for(int i = 0; i < n; i++) {
    for(int j = 0; j < n; j++) {
        for(int k = 0; k < n; k++) {
            cout << i;
        }
    }
}
```

Complexity:

```
O(n³)
```

---

# **6. Basic Recursion Complexity**

### 📘 Example 1: Linear Recursion

```cpp
void f(int n) {
    if(n == 0) return;
    f(n - 1);
}
```

Each call reduces `n` by 1.

Complexity:

```
O(n)
```

---

### 📘 Example 2: Fibonacci Recursion

```cpp
int fib(int n) {
    if(n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

Complexity:

```
O(2ⁿ)
```

Very slow.

---

### 📘 Important CP Insight

Recursive solutions must often be optimized using:

- Memoization
    
- Dynamic Programming
    

---

# **7. Space Complexity**

### 📘 Theory

Space complexity measures how much extra memory an algorithm uses.

Includes:

- Variables
    
- Arrays
    
- Recursive call stack
    

---

### 🔹 Example 1

```cpp
int a = 10;
```

Space:

```
O(1)
```

---

### 🔹 Example 2

```cpp
int arr[n];
```

Space:

```
O(n)
```

---

### 🔹 Recursion Space

```cpp
void f(int n) {
    if(n == 0) return;
    f(n - 1);
}
```

Call stack depth = `n`

Space:

```
O(n)
```

---

# 🔥 Time vs Space Tradeoff

Sometimes:

- We use extra memory to make code faster
    
- Or reduce memory but increase time
    

Example:

- Prefix sum uses O(n) space to reduce time to O(1) per query
